# FinPilot architecture

FinPilot is layered so that every calculation can be tested without the UI, and so that later levels
(budgeting, three-statement models, valuation) plug in as new content and new `core` modules.

```
ui (PySide6)  ──>  curriculum (content, grading, progression)  ──>  core (formula engine, finance, hotel)
     │                       │                                          ▲
     └──────────>  data (SQLite progress, .finpilot files)  export (Excel, PDF) ┘
```

## core/ (pure Python, no Qt)

| Module | Role |
|---|---|
| `formula/refs.py` | A1 references, `$` anchors, ranges, column letters. Max 500 rows x 52 columns. |
| `formula/parser.py` | Tokenizer and recursive-descent parser producing an AST. Excel precedence: `:` > unary `-` > `%` > `^` > `* /` > `+ -` > `&` > comparisons (so `=-2^2` is 4, `=2^3^2` is 64). Also `shift` (fill/copy), `references`, `function_names`, `to_formula`. |
| `formula/evaluator.py` | Walks the AST. Never raises: every failure becomes a `CellError` value that propagates like Excel. |
| `formula/functions.py` | 56 supported functions; `KNOWN_UNSUPPORTED` maps common Excel functions to `#UNSUPPORTED!` with an explanation. Lazy `IF`/`IFERROR`/`IFS`. |
| `formula/errors.py` | `CellError(code, detail)` with category (formula, input, missing, math) and a plain-English explanation. |
| `sheet.py` | Sheet model: cells (raw, role, format, note), dependency graph, recalculation in topological order with cycle detection (`#CIRC!`), undo/redo, fill, named ranges, `explain()`. |
| `finance.py` | Margins, break-even, EBITDA/EBIT/net income, operating cash flow, growth/CAGR, variance and favourability, NPV/IRR/PV/FV. Zero denominators return `None`. |
| `hotel.py` | 12-month hotel model: KPIs, weighted annual totals, scenarios, seasonality, sensitivity grid, volume/rate bridge, validation checks (pass/warn/fail with category). Fictional Harbour Crest Hotel data. |
| `hotel_sheet.py` | Layout of the 12-month model as a FinPilot sheet (rows, labels, reference formulas, formats). |
| `revenue_mgmt.py` | Group vs transient displacement analysis with break-even group rate. |
| `format.py` | Display formatting (accounting negatives in parentheses, `n/a` for undefined ratios). |

## curriculum/

- `content/*.json` – levels, skills, Level 1-3 lessons and projects, final assessment (generated by
  `tools/_l1.py`, `_l2.py`, `_l3.py`, `_fa.py`). `load()` validates everything at start-up and the test suite
  re-runs the validation: step order, prerequisites, skills, every reference formula passing its own grader,
  every numeric answer matching its formula.
- `grading.py` – number, choice, formula (behavioural, with perturbations) and written-rubric grading.
- `hotel_project.py` – the 10 Lab tasks, the task checker (typed values, wrong anchors, inconsistent rows,
  AVERAGE of ratios), and independent verification of the finished model against `core.hotel`.
- `progression.py` – item scores, unlocking, recommendations, XP, badges, competency ratings and the
  competency report.
- `drills.py` – parameterised practice drills (seeded random numbers).

## data/

- `db.py` – SQLite in `%APPDATA%\FinPilot\finpilot.db`: settings, lesson progress, step results,
  assessments, XP events (unique per reason+ref, so no double counting), badges, bookmarks, mistakes with
  spaced repetition, projects, skill evidence. Integrity check at start-up; a damaged file is moved aside and
  a fresh database is created (the learner is told). Zip backup/restore with validation and an automatic
  pre-restore backup.
- `projects.py` – `.finpilot` files: JSON with a SHA-256 checksum, atomic write (temp file + replace) and a
  `.bak` copy of the previous save. Loading reports clear `ProjectError` messages for empty, binary, damaged,
  foreign or incomplete files, and opens hand-edited files with a checksum warning.

## export/

- `excel.py` – openpyxl workbooks with real formulas (`_xlfn.` prefixes where Excel needs them,
  `fullCalcOnLoad`), named ranges, number formats, input/calc colouring, charts, a cover sheet stating that
  FinPilot did not recalculate the file in Excel. `read_back_sheet` reloads a workbook into FinPilot's engine
  for verification.
- `pdf.py` – ReportLab reports with a branded header/footer and drawn compass logo.

## ui/

- `app.py` (package root) – `create_app()` builds the QApplication, context and main window; `main()` adds
  logging, a global exception hook and the database-recovery notice; `--self-test` runs a headless check of
  the packaged app.
- `main_window.py` – sidebar navigation, menus, theme switching, onboarding on first run, routing of
  recommendations (`navigate(kind, ref)`), close prompt for unsaved models.
- `context.py` – `AppContext` shared by screens: database, curriculum, open project, signals, recording of
  items, mistakes, XP and badges.
- `theme.py`, `logo.py`, `widgets.py`, `charts.py`, `grid.py`, `questions.py` – design system and reusable
  components (including a wrapping `FlowLayout`).
- `pages/` – the 12 screens: onboarding, home, learning map, lesson, Modeling Lab, simulation, practice,
  final assessment, mistakes notebook, progress, portfolio, export center, settings.

## Adding a level

1. Write the lessons as JSON in `curriculum/content/levelN.json` (same schema as Level 3) and set the level's
   status to `available` in `levels.json`. Validation runs automatically.
2. Put new calculations in `core/` with unit tests, and new Lab projects next to `hotel_project.py`.
3. Add skills to `skills.json`; the competency dashboard picks them up.
